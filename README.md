Учебный проект: Telegram-бот, который показывает текущую погоду в указанном городе.

Бот принимает название города и возвращает актуальную информацию о погоде. Данные берутся из бесплатного API погоды.

Проект создан для отработки навыков:
- работы с Telegram Bot API,
- интеграции с внешними API,
- базового программирования на Python.

- Приветствие и инструкция по использованию.
- Запрос погоды по названию города.
- Отображение температуры.
